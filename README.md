# egg 🥚

An ideation room for [bb](https://github.com/get-bb/bb).

Point a room at a real folder, say or type a half-formed thought about one
small part of it, and a few different views of the real thing land side by
side. Keep what shows you something, drop the rest, go again.

Nothing here works yet. The first version is being built.
